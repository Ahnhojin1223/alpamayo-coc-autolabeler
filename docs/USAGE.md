# CoC 1건당 구독 사용량

측정일: 2026-11-01~02. 플랜은 ChatGPT Plus, Claude Pro입니다.

## 요약 (현재 설정 기준)

현재 `config/pipeline.json` 값인 Codex `gpt-6.1-sol` / `xhigh`, Claude `claude-opus-5-5` / `high`로 측정한 값입니다.

| 작업 (1건 기준) | Codex 5시간 | Codex 주간 | Claude 5시간 | Claude 주간 |
|---|---|---|---|---|
| 라벨 생성 | 약 1.7% | 약 0.3% | 약 0.3% 이하 | 0.1% 미만 |
| 검증 3단계 | 약 3.2% | 약 0.5% | 약 5% | 약 0.6% |
| **생성 + 검증 (같은 모델)** | **약 4.9%** | **약 0.8%** | **약 5.3%** | **약 0.7%** |

교차 검증이면 생성과 검증을 각 모델에 나눠서 더합니다.

| 구성 (1건 기준) | Codex 5시간 / 주간 | Claude 5시간 / 주간 |
|---|---|---|
| Codex 생성 + Claude 검증 | 약 1.7% / 0.3% | 약 5% / 0.6% |
| Claude 생성 + Codex 검증 | 약 3.2% / 0.5% | 약 0.3% 이하 / 0.1% 미만 |

사용량은 정수 퍼센트로만 표시되므로 모두 어림치입니다.

| 작업 | Codex `xhigh` | Claude `high` |
|---|---|---|

| 구성 | 1건 소요 시간 |
|---|---|
| Claude 생성 + Claude 검증 | 약 1분 |

3건을 순서대로 돌린 시간을 3으로 나눈 값입니다. 프로그램 시작과 영상 처리 시간은 포함하고, 재시도 대기와 사용량 한도 대기는 뺐습니다.

## thinking별 비교

| 검증 3단계 5시간 사용량 | 약 2.3% | 약 3.2% | 약 3.7% | 약 5% |

- 출력 토큰에는 thinking 토큰이 포함됩니다.
- Claude 라벨은 `high`와 `medium`의 토큰이 거의 같았습니다.
- Codex 라벨은 `xhigh`에서 출력이 약 4배로 늘었지만, 5시간 사용량 표시는 같은 5%였습니다. 표본이 작아 차이가 없다고 단정할 수는 없습니다.
- `xhigh`/`high`의 검증 9회는 단계마다 프로그램을 새로 시작해 시작 시간이 더 들어갔습니다. 단계당 약 10초입니다.
- Codex 검증의 입력 토큰은 `low` 행당 평균 24,402~109,203에서 `xhigh` 99,492~220,282로 늘었습니다. 이유는 확인하지 못했습니다. Claude 검증의 입력 토큰은 두 설정에서 같았습니다.

## 계산 방법

- **Codex:** 단계별 증가량을 건수로 나눴습니다.
- **Claude 검증 `medium`:** 라벨 없이 검증 9회만 돌린 3차에서 11%가 올랐으므로 1건분은 약 3.7%입니다.
- **Claude 검증 `high`:** 4차의 15회에서 초기화 전 78%→86%(8%), 초기화 후 0%→17%(17%)로 모두 25%가 올랐으므로 3회당 약 5%입니다. 주간은 5건분에 64%→67%여서 1건당 약 0.6%입니다.
- **Claude 라벨:** 라벨 3건 단계에서 표시값이 두 번 모두 변하지 않았고, 1차의 "라벨 3건 + 검증 9회"와 3차의 "검증 9회"가 똑같이 11%였습니다. 그래서 3건에 1% 미만으로 보고 1건을 0.3% 이하로 적었습니다.
- Claude 라벨의 입력 토큰이 검증 1단계보다 많은데도 사용량이 훨씬 적은 이유는 확인하지 못했습니다.

## 측정의 한계

- 한도는 계정 전체 기준이어서, 측정 중 다른 곳에서 쓴 사용량이 있으면 함께 잡힙니다.
- Claude 5시간 창은 Claude 앱과 Claude Code가 공유합니다. 측정을 진행한 Claude Code 세션의 사용량도 Claude 값에 섞였을 수 있어, Claude 값은 실제보다 클 수 있습니다.
- 사용량 표시는 호출 직후 바로 오르지 않을 수 있습니다. 4차에서 Claude 호출이 없던 대기 중에도 84%에서 86%로 올랐습니다.
- Codex 입력 토큰은 같은 단계에서도 크게 달랐습니다(3단계 54,545~163,872). 토큰보다 퍼센트를 기준으로 보는 편이 낫습니다.
- 두 회사의 한도 기준이 달라 토큰 수로 두 모델을 직접 비교할 수 없습니다.
